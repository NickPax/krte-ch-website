## Gateway Crash-Loop Fixed
- **Problem:** Gateway was crashing every 30 minutes with "No API provider registered for api: undefined"
- **Root cause:** Heartbeat configured to use `ollama/llama3.2:3b` but provider wasn't resolving correctly
- **Fix:** Switched heartbeat model to `anthropic/claude-sonnet-4-5` via config.patch
- **Impact:** Morning Momentum cron job (8am) was missed because gateway restarted at 08:08
- **Lesson:** Ollama provider works for main sessions but has issues with heartbeat context
