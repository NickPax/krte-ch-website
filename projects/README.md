# Projects

Central hub for all project documentation, marketing materials, and assets.

## Structure

Each project has three folders:

```
projects/<name>/
├── README.md      # Project overview and status
├── docs/          # Technical documentation, specs, decisions
├── marketing/     # App Store materials, copy, screenshots (Patrik's domain)
└── assets/        # Logos, icons, graphics, raw files
```

Researched questions are saved to `/nest/` with links from the Nest items in events.json.

## Usage

When working on a project:
1. Check/update the project README
2. Add technical docs to `docs/`
3. Marketing materials go to `marketing/` (coordinate with Patrik)
4. Raw assets (images, icons) go to `assets/`
